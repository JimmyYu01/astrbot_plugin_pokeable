# astrbot_plugin_pokeable

让 AstrBot 能够主动处理「戳一戳」（Poke）消息段，并支持按概率主动回复。

## 功能

- **工具调用**：注册 LLM 工具 `send_poke`，让模型可以主动戳一戳指定用户（群聊 / 私聊均支持）。
- **主动回复**：当有人戳机器人时，可按配置的概率触发一次 LLM 回复。

## 配置

在插件配置页设置 `主动回复戳一戳`：

| 配置项 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `enable` | bool | `false` | 是否启用「被戳时主动回复」 |
| `probability` | float | `0.0` | 触发回复的概率，范围 `0` ~ `1`（滑动条，步进 0.01） |

> 默认全部关闭：只有显式启用并设置概率后，被戳才会触发回复。

## 使用

### 1. LLM 工具 `send_poke`

模型在被要求戳某人时会调用该工具：

- 参数 `user_id`：目标用户 ID；**留空则戳当前消息发送者**。
- 私聊：直接戳 `user_id`。
- 群聊：在 `group_id` 内戳 `user_id`。
- 返回示例：`你戳了戳 <user_id>`；非 aiocqhttp 平台返回 `当前消息平台暂未适配`。

例如对机器人说「戳一下我」，它就可能调用该工具戳你。

### 2. 被戳时主动回复

当机器人被别人戳一戳，且满足以下条件时，会触发一次 LLM 回复：

1. `enable` 为 `true`；
2. 命中概率 `probability`（`random() < probability`）；
3. 消息链中**任意位置**存在指向机器人自身的 `Poke` 段。

命中后会以「`<发送者ID> 戳了戳你`」作为输入交给默认 LLM，由模型生成回复。

## 限制

- **仅支持 aiocqhttp（OneBot v11）**，其它平台不生效。
- 「主动回复」走的是 **默认 LLM 链路**，需要启用 AI 能力；若关闭 AI，则只会被戳而不会回复。
- 概率回复是随机的：即使满足条件，也可能不回复（`probability` 越小越少回）。

## 安装

放入 AstrBot 的 `data/plugins/` 目录，或直接在插件页安装。
